ゲームモード: 左下スティック=移動キー / ボタン=押している間キーを押下 / 画面をなぞる=視点（マウス相対移動） / タップ=左クリック。 コントローラー（仮想Xbox）: Joy-Con をそのまま PC の Xbox コントローラーとして使えます（PC に ViGEmBus が必要）。
コントローラー（キー割り当て）: Lスティック=移動 / Rスティック=視点 / ZR=左クリック / ZL=右クリック / A・B・X・Y=ボタン欄の1〜4番目 / L・R=5・6番目 / 十字キー=7〜10番目
