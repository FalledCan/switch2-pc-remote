# Switch Remote — Switch 2 から PC を遠隔操作

同じ LAN 内の Nintendo Switch 2 から、Windows PC の画面を見てタッチ操作・文字入力できるソフトです。
Switch 2 に自作アプリは入れられないため、本体に隠されている**キャプティブポータル用ブラウザ**
（Wi-Fi ログイン画面を表示するブラウザ）をクライアントとして使います。

```
Switch 2 ──DNS問い合わせ──▶ PC (内蔵DNS: 全部PCのIPを返す)
Switch 2 ──接続テスト(HTTP)─▶ PC (Webサーバー: 操作画面へ誘導)
          ◀─「ネットワークへの登録が必要です」→ ブラウザが開く
ブラウザ  ◀── JPEG 画面映像 ── PC (mss でキャプチャ)
ブラウザ  ── タッチ/文字入力 ──▶ PC (SendInput でマウス・キーボード操作)
```

## 必要なもの
- Windows 10/11、Python 3.10 以上
- PC と Switch 2 が同じ Wi-Fi / LAN に接続されていること

## 使い方

1. `start.bat` をダブルクリック（初回は依存ライブラリ mss / Pillow を自動インストール）。
   - Windows ファイアウォールの許可ダイアログが出たら「プライベート ネットワーク」を許可。
   - 出ない／つながらない場合は `setup_firewall.bat` を**管理者として実行**して受信ルールを追加。
2. コンソールに表示される **IP アドレス** と **PIN** を確認。
3. Switch 2 で
   `設定 > インターネット > インターネット設定 > 接続中のネットワーク > 設定の変更`
   - DNS 設定: **手動**
   - 優先 DNS / 代替 DNS: **PC の IP**（コンソールに表示されたもの）
   - 保存して **接続テスト** → 「ネットワークへの登録が必要です」→ **次へ**
4. ブラウザが開いたら PIN を入力して接続。

使い終わったら Switch 2 の DNS 設定を **自動** に戻してください（戻さないと通常の通信ができません）。

## 操作方法

| モード | 操作 | 動作 |
|---|---|---|
| 直接タッチ | タップ | その位置をクリック |
| | 長押し / 2本指タップ | 右クリック |
| | 1本指ドラッグ | ドラッグ（範囲選択・ウィンドウ移動） |
| | 2本指ドラッグ | スクロール |
| トラックパッド | 1本指スライド | カーソル移動（細かい操作向け） |
| | タップ | 現在位置をクリック |
| ブラウザのポインター（Lスティック+A） | クリック・移動 | 直接タッチと同様 |

下部バー: Esc / Tab / Enter / BS / Win、**右クリック**（次のタップを右クリックに）、
**ドラッグ固定**（左ボタン押しっぱなし）、**ズーム**（1x〜3x、カーソル位置を自動追従）。
**⌨ 文字入力** で Switch のソフトウェアキーボードから日本語を含む文字を送信できます。
☰ メニューにショートカット（コピー/貼り付け/Alt+Tab/タスクマネージャー等）、
解像度・画質・モニター切替・転送方式があります。重い場合は 480p / 画質「低」を選んでください。

## ゲームで遊ぶ（Joy-Con 対応）

下部バーの **🎮 ゲーム** でゲームモードになります。

- **仮想 Xbox コントローラー**（推奨）: Joy-Con の入力を PC 上の Xbox 360 コントローラーとして再現します。
  Xbox コントローラー対応のゲームならそのまま遊べます。初回のみ `install_gamepad.bat` で
  vgamepad と ViGEmBus ドライバーを導入してください。ボタン配置は「刻印どおり（A→A）」「位置どおり」から選べます。
- **キー割り当て**: ドライバー不要。L スティック=WASD、R スティック=視点（マウス相対移動）、ZR/ZL=左右クリック、
  A/B/X/Y=メニューの「ボタン」欄の 1〜4 番目。キーボード・マウス専用ゲーム向け。
- コントローラーが無いときは画面上の仮想スティックとボタンで操作できます。

遅延を減らすコツ: メニューで解像度 480p〜720p・画質「低〜中」にする。左上の表示で fps と往復時間を確認できます。
映像は DXGI キャプチャ + libjpeg-turbo で変換し、WebSocket で最新フレームだけを送ります（表示が追いつかない分は捨てる）。

## コマンドラインオプション

```
python -m switch_remote [--ip IP] [--port 80] [--pin 1234 | --no-pin]
                        [--monitor 1] [--fps 30] [--no-dns]
```

- `--monitor 0` で全モニター結合表示。ブラウザのメニューからも切替可能。
- `--no-dns` にした場合は、ルーターの DNS 設定などで誘導するか、ブラウザで URL を直接開いてください
  （PC やスマホのブラウザからも `http://<PCのIP>/` で利用できます）。

## 動作確認
- Switch 2 実機で接続・操作できることを確認済み（2026-11-02）。
  接続テストの宛先は `ctest.p01.ctest.srv.nintendo.net`（IPv6 用に `ctest-ipv6.p01.ctest.srv.nintendo.net`）でした。

## 注意・制限
- 本ソフトは任天堂とは関係のない非公式ツールです。Switch 本体の改造は行わず、本体標準のブラウザを使います。
- Switch のブラウザでは **X ボタンでブラウザが終了**します（ページ側で止められません）。ゲームモードでは − ボタンなどを X の代わりに使えます。
- 接続テストは HTTP ポート 80 宛てなので、80 番を他のソフト（IIS など）が使っていると誘導できません。
- 管理者権限で動いているウィンドウ（タスクマネージャー等）を操作するには、本ソフトも管理者として実行してください（Windows の UIPI 制限）。
- 音声は転送されません。Switch のブラウザは高速ではないため、動画やゲームより事務操作向けです。
- PIN は起動ごとにランダムに変わります。信頼できない LAN では使用しないでください（通信は暗号化されません）。

## 構成
- `switch_remote/server.py` — HTTP サーバー、認証、入力 API、起動処理
- `switch_remote/capture.py` — 画面キャプチャ・JPEG 化（変化がないときは送信を抑制）
- `switch_remote/input_win.py` — Win32 SendInput によるマウス・キーボード注入
- `switch_remote/dns_server.py` — 接続テストを誘導する最小 DNS サーバー
- `switch_remote/web/` — Switch のブラウザで動くクライアント（ES5 / タッチ・コントローラー対応）
